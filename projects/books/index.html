Exercise 10: Fetching Data using jQuery $.ajax()

When the "Load Books" button is clicked, an Ajax GET request is made using jQuery's $.ajax() method to retrieve a list of books from a hypothetical API endpoint (https://api.example.com/books). The JSON response is parsed, and titles, authors, and metadata are rendered dynamically.

No Books Loaded Yet

Click the "Load Books" button above to initiate jQuery's $.ajax() call.

💻 View Under-the-Hood jQuery $.ajax() Implementation ▼ 
$.ajax({
    url: "https://api.example.com/books", // Or local JSON mock
    type: "GET",
    dataType: "json",
    beforeSend: function() {
        $('#loadBooksBtn .spinner').show();
    },
    success: function(data) {
        // Parse JSON response and display books on the webpage
        renderBooks(data);
    },
    error: function(xhr, status, error) {
        console.error("AJAX Error: " + status, error);
    },
    complete: function() {
        $('#loadBooksBtn .spinner').hide();
    }
});
